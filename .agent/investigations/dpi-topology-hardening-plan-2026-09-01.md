right. Deterministic topology already models boundary coordinates, but the
physical acceptance matrix did not cover left-negative/above-origin layouts,

## Safety boundary

Physical topology is an environment capability. The operator-controlled
protocol snapshots display state, verifies any temporary layout/scale before
input, runs a bounded exact-candidate cell, and verifies restoration. Registry
hacks, blind Display Settings automation, unrelated-window manipulation,
unsupported display mutation, and destructive automated hot-unplug are out of
scope. Synthetic topology never satisfies a physical gate.

Production code remains unchanged unless a retained valid `FAIL_PRODUCT` or
deterministic policy defect proves a concrete invariant violation.
