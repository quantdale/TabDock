# Planner → Executor Handoff

Use this workflow when a planning campaign is requested. A planner writes `.agent/EXECUTION_PROMPT.md` only after auditing actual code/tests/docs, recent commits/diffs, useful issues/PRs, and native state. It defines Status, Planned-From, target branch, campaign objective, scope, workstreams, constraints, validation, acceptance/completion gates, and Git/reporting requirements; then hands off without implementing. Commit or push only when the user has explicitly authorized it, as required by `AGENTS.md`.

For `/goal continue`: read repository instructions, this file, the execution prompt if present, and `.agent/STATE.md`; reconcile current Git/implementation; resume an ACTIVE prompt from the first incomplete requirement without redoing landed work; validate, fix introduced Critical/High regressions, and update state. Otherwise continue the user's active objective from native state. This workflow does not independently authorize commits, pushes, or a new campaign.
