## ADDED Requirements

### Requirement: Managed feedback lifecycle qualification SHALL exercise actual controls

The deterministic lifecycle suite SHALL include actual styled managed-control creation, attachment, teardown, reload and collectability checks under enabled and reduced motion. These checks SHALL settle owned dispatcher/animation work and distinguish surviving external roots from test-local references. Prescribed synthetic resource counters SHALL remain labeled synthetic and SHALL NOT substitute for actual control-lifetime assertions or claim physical/native-resource qualification.

#### Scenario: A rooted property observer fails actual lifecycle qualification

- **WHEN** a feedback observer retains discarded actual controls after teardown and settled-work collection
- **THEN** the managed lifecycle check fails even if synthetic resource snapshots are flat

#### Scenario: Repeated styled-control churn is non-invasive

- **WHEN** the managed feedback lifecycle suite runs in ordinary headless Windows CI
- **THEN** it creates no visible application windows, sends no physical input, touches no production state, and reports only managed collectability evidence
